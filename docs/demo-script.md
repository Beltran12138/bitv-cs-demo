# bitV 客服机器人 Demo 对话脚本

> 演示用途。每个场景展示从问题发起 → 机器人响应 → 追问 → 解决的完整多轮对话流程。
> 展示时建议按场景顺序演示，高频场景优先。

---

## 场景 1：新用户注册 + KYC 流程

**背景：** 用户刚下载 App，不知道如何开始。

| 角色 | 内容 |
|------|------|
| 用户 | 我想开户，怎么注册账号？ |
| 机器人 | 注册步骤：① 填写邮箱并设置密码；② 验证邮箱（检查垃圾邮件文件夹）；③ 完成 KYC 实名认证，全程约 5 分钟。KYC 通过后即可使用全部功能。 |
| 用户 | 验证邮件一直没收到 |
| 机器人 | 请先检查垃圾邮件/广告邮件文件夹；若仍未收到，点击注册页面"重新发送"按钮，确认邮箱地址拼写正确。等待 3 分钟后仍未收到，可联系客服。 |
| 用户 | 好了，KYC 需要什么材料？ |
| 机器人 | KYC 需要：① 政府颁发的有效证件（护照或身份证）；② 手持证件的清晰自拍照。审核通常在 1 个工作日内完成。完成后可解锁更高提币额度和完整平台功能。 |
| 用户 | L1 和 L2 有什么区别？ |
| 机器人 | L1 基础认证提币限额 10,000 USDT/天；L2 高级认证（额外需视频认证+地址证明）提币限额 500,000 USDT/天。L2 一般由系统邀请大额用户，或可联系客服申请。 |

## 场景 2：提币未到账排查

**背景：** 用户提币 3 天仍未收到，非常焦虑。

| 角色 | 内容 |
|------|------|
| 用户 | 我提币已经 3 天了还没到账！ |
| 机器人 | 非常抱歉给您带来困扰。请先确认：① 网络类型是否与接收地址一致（如选了 TRC20 但地址是 ERC20）；② 在区块链浏览器用 TxID 查询链上状态。TxID 可在"交易记录"中找到。 |
| 用户 | 链上已经显示成功了，但平台还没收到 |
| 机器人 | 链上确认成功但平台未显示，请提交客服工单并附上 TxID（交易哈希）。我们将人工核查，通常 1 个工作日内处理完毕。 |
| 用户 | 我怎么提交工单？ |
| 机器人 | 路径：账户中心 → 帮助与支持 → 提交工单。请在工单中注明：TxID、提币金额、提币币种、发起时间。也可直接点击"转人工"由客服协助处理。 |

## 场景 3：永续合约强平预防

**背景：** 新手用户开了高杠杆合约，担心被强平。

| 角色 | 内容 |
|------|------|
| 用户 | 永续合约最高多少倍杠杆？ |
| 机器人 | bitV 永续合约最高支持 100x 杠杆，资金费率每 8 小时结算一次（00:00、08:00、16:00 UTC）。新手建议从低杠杆开始，并设置止损订单控制风险。 |
| 用户 | 什么情况会被强平？ |
| 机器人 | 当保证金率低于维持保证金水平时触发强平。预防措施：① 设置止损订单；② 不使用过高杠杆；③ 保持充足保证金余额。强平价格可在持仓页面实时查看。 |
| 用户 | 逐仓和全仓有什么区别？ |
| 机器人 | 全仓（Cross Margin）：账户所有可用余额作为保证金，抗风险能力强但影响全账户；逐仓（Isolated Margin）：每个仓位独立保证金，最大亏损仅为该仓位保证金，适合控制单笔风险。 |
| 用户 | 快强平了怎么办 |
| 机器人 | 有两个选项：① 追加保证金——将资金转入合约账户，提高保证金率，降低强平价格；② 减仓——部分平仓减少持仓，降低所需保证金。建议操作前先在页面确认当前保证金率和强平价格。 |

## 场景 4：账户被盗应急处理

**背景：** 用户发现账户有未授权交易，非常紧张。

| 角色 | 内容 |
|------|------|
| 用户 | 我的账户被盗了！有人在转我的钱！ |
| 机器人 | 请立即采取以下措施：① 马上在"设置 → 账户安全"中冻结账户；② 修改密码；③ 更换 2FA 绑定设备。操作完成后，通过官方渠道提交工单说明情况，切勿通过第三方处理。 |
| 用户 | 账户在哪里冻结？ |
| 机器人 | 路径：App → 右上角头像 → 账户设置 → 安全 → 账户冻结。冻结后所有提币和交易功能将立即暂停。 |
| 用户 | 我的手机也不在身边，2FA 用不了 |
| 机器人 | 如有备用恢复码：登录页选择"使用恢复码"；若无恢复码：请尽快提交人工解绑申请，需提供身份证件和视频验证。审核需 1–3 个工作日，期间提币功能冻结以保护资产安全。 |

## 场景 5：订单未成交排查

**背景：** 用户挂了限价单，等了很久没有成交。

| 角色 | 内容 |
|------|------|
| 用户 | 我挂的限价单为什么一直没成交？ |
| 机器人 | 限价单未成交常见原因：① 市价未到达您的挂单价格；② 账户可用余额不足（部分被其他挂单冻结）；③ 该交易对流动性不足。可在"交易界面 → 当前委托"查看订单状态。 |
| 用户 | 可用余额不足是什么意思？ |
| 机器人 | 您账户的"冻结余额"是被未成交挂单占用的资金，撤单后立即释放。如果您有多笔挂单，部分资金可能已被锁定，导致新订单可用余额不足。 |
| 用户 | 我不想等了，想直接成交 |
| 机器人 | 您可以撤销当前限价单（交易界面 → 当前委托 → 撤销），改用市价单立即成交。如果希望"要么全部成交要么取消"，下单时可选择 FOK 模式。 |

## 场景 6：费率查询 + VIP 升级

**背景：** 用户交易量增加，想了解费率优惠。

| 角色 | 内容 |
|------|------|
| 用户 | 现货手续费是多少？ |
| 机器人 | bitV 现货交易手续费：maker = taker = 0.1%。持有 BTV 平台代币可享折扣，最低至 0.05%；VIP 用户可享更低费率。 |
| 用户 | VIP 怎么升级，有什么好处？ |
| 机器人 | VIP 等级基于过去 30 日现货+合约交易量自动计算，每日更新：VIP1（≥10万 USDT）手续费 0.09%；VIP2（≥100万 USDT）0.08%；VIP3（≥1000万 USDT）0.07%。高 VIP 还享有专属客服和更高提币额度。 |
| 用户 | BTV 折扣和 VIP 折扣能叠加吗？ |
| 机器人 | BTV 折扣和 VIP 折扣可以叠加。例如 VIP1 费率 0.09%，持有 5000 BTV 再享 7 折，最终费率约 0.063%。具体叠加规则以账户页面实时显示为准。 |

## 场景 7：充错网络求助

**背景：** 用户将 USDT 充值时选错了网络，资产未到账。

| 角色 | 内容 |
|------|------|
| 用户 | 我充值 USDT 选错网络了，用了 ERC20 但地址是 TRC20 的，怎么办？ |
| 机器人 | 对于充错网络的情况，bitV 支持部分跨链资产找回，需人工处理并收取服务费。请提交工单，附上：① 发送交易的 TxID；② 发送的网络类型（ERC20）；③ 您平台的充值地址网络类型（TRC20）。 |
| 用户 | 能找回的概率高吗？多久能处理？ |
| 机器人 | 主流资产（如 USDT ERC20/TRC20 互转）找回成功率较高，通常需 3–7 个工作日。非标准网络或小币种无法保证找回。找回结果以工单回复为准，操作前务必核实网络类型以避免此类情况。 |

## 场景 8：合规与税务查询

**背景：** 用户年末需要申报资产收益，询问平台税务支持。

| 角色 | 内容 |
|------|------|
| 用户 | 平台有没有税务报表可以下载？ |
| 机器人 | 有的。bitV 提供年度交易记录导出（CSV 格式），路径：账户设置 → 导出记录 → 选择年度。导出请求通常在 24 小时内发送至您的注册邮箱。 |
| 用户 | 美国用户需要 1099 表格吗？ |
| 机器人 | 是的。从 2025 税年（2026 年初发送）起，bitV 将按 IRS 要求向美国用户发送 Form 1099-DA，包含数字资产销售总收益数据。具体税务申报建议咨询专业税务顾问，平台提供数据但不提供税务建议。 |
| 用户 | 我的账户被 AML 审查限制了，怎么配合？ |
| 机器人 | AML 审查期间，您可能需要提供：资金来源证明、交易目的说明、相关转账凭证。请按工单要求及时提交材料，配合审查可加快账户恢复。审查结果通过工单系统通知您。 |
